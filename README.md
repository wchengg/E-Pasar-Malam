# E-Pasar Malam — Online Night Market Platform

Hi! 👋 I'm someone who really enjoys visiting pasar malam, exploring different stalls, and trying various foods. 
However, sometimes it can be difficult to visit a night market due to time constraints, busy schedules, or distance.
This inspired me to develop **E-Pasar Malam**, an online night market platform, as my Diploma Final Year Project. 
The goal is to bring the pasar malam experience online, allowing users to browse products and place orders conveniently.

The platform includes separate interfaces for users, merchants, administrators, and delivery personnel to support the overall ordering process.

### 🛠️ Technologies Used
- PHP
- HTML
- CSS
- JavaScript
- MySQL

### ✨ Project Modules
- User Management
- Merchant Management
- Admin Management
- Delivery Management

This project allowed me to apply my knowledge of web development and database management while exploring how technology can make traditional night market shopping more convenient.
